**한계:** 스토어 리뷰는 불만족 편향 표본이다. 문제의 **존재**는 확인되지만 **비율은 알 수 없다.** (미국 평점 4.6 / 43,000 ratings)

## 이 조사의 결론

HelloTalk 사용자가 **칭찬할 때 하는 말은 전부 「친구」**고, **비판할 때 하는 말은 「학습」**이다.

> 🇰🇷 *"저는 **친구 사귀기** 좋은 거 같아요"* (5★)
> 🇰🇷 *"첫날에 바로 **일본 언니랑 친해지고** 너무 재밌더라구요"* (5★)
> 🇺🇸 *"made some great **friends**"* (5★)
> 🇯🇵 *"**学習の質としては低い**です。学習目標ならやめておくべきです"* (1★)

즉 이 앱이 실제로 배달하는 가치는 **외국 친구**이고, 언어 학습은 그 명분이다.
아래 문제들은 전부 **"친구가 되는 것을 방해하는 것"** 순으로 정렬했다.

## 핵심 문제 8개

### 1. 학습 언어를 설정해도 무관한 사람만 뜬다 🔴 최신

2026년 7월 업데이트로 **무료 회원은 상대의 모국어·학습언어를 선택할 수 없게** 됐다. 세 시장에서 동시에 폭발 중.

> 🇯🇵 2026-08-08 (1★) 자신이 학습하고 싶은 언어를 설정했는데도 전혀 관계없는 언어 페어 상대만 추천된다. 이제 언어학습 앱이 아니라 **그냥 랜덤 채팅(채팅 룰렛) 상태**다.
> 🇯🇵 2026-07-21 (1★) 무료 회원은 언어 파트너의 모국어와 학습언어를 선택할 수 없게 됐다. **마이너스 조정으로 유료 회원을 늘리려는 시도는 최악.**
> 🇰🇷 2026-07-21 (1★) 이제 학습언어 한개조차도 무조건 결제해서 선택해야됨.

**→ 우리 축과 정면으로 겹친다.** 발견·언어 설정을 영구 무료로 두는 것만으로 카운터가 된다.

### 2. 메시지가 300통 오거나, 2통도 안 온다

같은 앱 안에서 과부하와 무응답이 공존한다. 분배 실패.

> 🇯🇵 2026-07-31 (3★) 메시지가 너무 많이(**300건 정도**) 와서 거의 답장을 못 한다.
> 🇺🇸 2026-06-23 (2★) **딱 두 통** 받았다.
> 🇰🇷 2026-05-31 (2★) 한국여잔데 **메세지 한번도 못해봄.**

**공식 FAQ에 「Why does nobody reply to my messages?」 항목이 존재한다.**

### 3. 30명을 만나도 친구는 1~2명만 남는다

> 🇯🇵 2026-05-11 (3★) 30명 정도와 대화해도 **1주일 뒤엔 1~2명밖에 안 남는다.** 제대로 된 사람을 만나면 초대박이라는 감각으로 쓰는 게 좋다.

빈 채팅창에서 시작해 스몰토크를 못 넘긴다. 일본에는 **「言語交換が続かない」(언어교환이 안 이어진다) 공략 글이 여러 개** 존재한다 — 이어가고 싶은데 방법을 모르는 사람이 많다는 뜻.

### 4. 연애 목적 유입과 로맨스 스캠

> 🇰🇷 2026-06-30 (1★) **100명중 99명이 로맨스 스캐머**입니다. 카톡 라인 왓츠앱 인스타로 **옮겨가서** 나중에 돈이나 게임카드 등 요구합니다.
> 🇰🇷 2026-07-20 (1★) 1.먼저 연락이 왔다? 2.**라인아이디를 물어 본다?** 3.부업한다고 오더 수수료 업무를 본다? 사기입니다.
> 🇯🇵 2026-06-05 (1★) 일본인 남자, 만남 목적이 많다. 외국어를 거의 못하는데도 여자와 알고 지내려고 쓴다. **매칭앱 가라.**
> 🇰🇷 2026-06-15 (1★) 지금은 앱 방향성도 **노골적으로 연애앱**이고

**스캠은 항상 외부 메신저로 나간 뒤 완성된다.** 탐지 지점이 명확하다는 뜻이기도 하다.

### 5. 여성이 안전하게 쓰려면 설정을 외워야 한다

> 🇯🇵 2026-08-07 (2★) **모먼츠 게시물을 동성에게만 표시되게 해주세요😭** 만남을 원하는 건지 이상한 댓글만 온다. 무섭다… 언어교환 앱인데 기분 나쁘다.
> 🇯🇵 2026-07-13 (1★) 「여성에게 위험한 앱입니다」 — **하루에 차단할 수 있는 인원수에 제한**이 있다 / **메시지 수신 범위를 설정할 수 없다** / 단순히 셀카를 올렸을 뿐인데 노출 사진들과 함께 셀피 탭에 분류된다. **그 탭 열람은 별도 과금.**
> 🇰🇷 2026-07-20 프사를 제 얼굴로 바꾸자마자 인도인? 파키스탄 남자 계속 연락오고요

**사용자가 우리 기능을 리뷰로 직접 요청하고 있다** (동성 한정 노출).

**반대 의견도 있다:**
> 🇯🇵 2026-05-30 (3★) 불특정 다수와 연결되는 앱에 "실제로 만나 친구가 되고 싶다", "잘하면 사귀고 싶다"는 목적을 가진 사람이 많은 건 당연하다.

### 6. 앱을 지우면 친구를 잃는다

채팅 기록이 **서버가 아니라 기기에만** 저장된다. 앱 삭제 시 복구 불가. 사전 수동 백업이 필요한데 그걸 알 방법이 없다.

> HelloTalk 모먼츠 게시물: *"문제가 생겨 앱을 재설치했더니 **대화가 전부 사라졌습니다.** 저와 얘기 중이셨다면 다시 메시지 주세요."*
> HelloTalk 모먼츠 게시물: *"일어나보니 **채팅이 전부 사라졌어요** 😭😭💔"*

**공식 FAQ에 「Why is my message history gone?」 항목이 존재한다.**

이건 "잘 되면 카톡·라인으로 옮겨간다"는 이탈의 숨은 원인이기도 하다. **소중한 관계일수록 안 사라지는 곳으로 옮길 이유가 커진다.**

### 7. 번역이 막혀서 대화 자체가 성립 안 한다

> 🇰🇷 2026-07-06 저도 영어에 미성숙하고 상대방도 한국어에 미성숙해서 **번역기의 도움을 받아야 원활하게 소통**이 가능한데 번역기 기능이 유료라서
> 🇯🇵 2026-06-17 (2★) 번역 기능을 몇 번 쓰면 바로 구독 결제를 유도한다. **그래서 매번 복붙하고 있다.**

가장 약한 사용자에게, 가장 필요한 순간에 과금한다. **번역 원가가 사실상 0인 2026년에.**

### 8. 사유 없는 계정 정지

> 🇯🇵 2026-06-04 (1★) 사전 경고 없이 계정이 동결됐다. 데이터를 백업할 시간조차 없다. 같은 단말기에서 신규 가입도 안 된다. 이유는 **「신고가 있었다」고만** 설명하고 어떤 규약을 위반했는지는 밝히지 않았다.
> 🇰🇷 2026-06-28 (1★) 성적인 이야기나 만남 목적의 사람들이 있어 채팅룸을 지웠는데, **그 사람들이 신고를 했는지 임의로 로그아웃**되고 로그인도 불가능해졌습니다.

**신고한 사람이 오히려 정지되는 구조.** 평생 VIP 구매자도 밴 + 환불 거부 사례 다수.

## 그 외 관찰 (근거는 있으나 우선순위 낮음)

**과금** — 광고 과다, 보이스룸 무료 체험 24시간→30분 축소(2026.7), 광고를 봐도 혜택 미지급, 구독 취소 시 잔여기간 미보장, 프로필 편집도 유료라는 리뷰, 과금해야 노출됨

**피드** — "내 보이스룸 오세요" 홍보글이 일반 글과 섞임, 셀카·좋아요 경쟁, 유튜브 링크만 올리는 사용자

**학습** — 교정해주는 사람을 찾기 어려움(언어별 편차 큼), 초보자는 말이 안 통해 어색해져 이탈, 상대가 ChatGPT 복붙

**AI** — 강제하면 *"AI Slop, basically unusable"*(2★), 선택형이면 *"absolutely LOVE how the AI is completely optional"*(5★)

**안정성** — 로그인·재가입 불가, 알림 꺼도 수신, 위치 무단 노출, 렉·버그 다수 (실행력 문제라 우리가 배울 건 없음)

## 주목할 신호 2개

### 공식 FAQ가 실패를 문서화하고 있다

- **Why does nobody reply to my messages?**
- **Why is my message history gone?**

회사가 핵심 상호작용의 실패를 공식 문서로 설명한다는 것은, 사용자 교육의 문제가 아니라 **구조적 실패**라는 뜻이다.

### 사용자가 제품을 개조해서 쓰고 있다

**확인된 것 (2026)**

| 사용자가 하는 것 | 원래 필요했던 기능 |
| --- | --- |
| 모먼츠에 "대화 날아갔어요, 다시 메시지 주세요" 게시 | 서버 기반 기록 보존 |
| 프로필에 「공부 목적」이라고 써서 접근을 거름 | 목적 필터 / 동성 한정 노출 |
| 번역 제한을 매번 복붙으로 우회 | 무제한 번역 |
| 동성에게만 보이게 해달라고 리뷰로 요청 | 동성 한정 노출 설정 |

**미검증 가설 (사내 관찰 · 외부 근거 못 찾음)**

- 모먼츠에 "전화할 사람?" "하트 누르면 메시지" 형태로 글을 올려 상대를 구한다
- 하트를 "언어 없이 의사를 표시하는 신호"로 쓴다

→ **「지금 말할래요」 보드 설계의 근거인데 아직 검증되지 않았다.** 사용자 인터뷰나 모먼츠 직접 관찰로 확인 필요.

## 제품 결정 반영 현황

| 문제 | 우리 대응 |
| --- | --- |
| 1. 언어 필터 유료화 | 발견·언어 설정 **영구 무료** |
| 2. 메시지 양극화 | 손들기(쌍방 동의) + 수신 상한 + 응답률 우대 |
| 3. 30명→1~2명 | 주제·턴 타이머 세션 + 「다음에 또」 |
| 4. 스캠 | 세션 우선 구조 + 연락처 교환 경고 + 행동 신호 탐지 |
| 5. 여성 안전 | **동성 한정 토글 무료** + 무제한 차단 + 수신 범위 설정 |
| 6. 데이터 소실 | **서버 저장 기본.** 수동 백업 불필요 |
| 7. 번역 유료 | 무제한 무료 |
| 8. 사유 없는 밴 | 사유 명시 + 이의 절차 + 신고자 보호 + 단계적 제약 |
| AI | 선택형 고정 |
| 광고 | 없음 |

### 아직 답이 없는 것

- **수익 모델** — "친구 사귀기가 본질"이면 수익화가 자연히 「만남 기회를 파는」 쪽으로 끌린다. HelloTalk이 간 길이다. 노출을 팔지 않으면서 무엇으로 벌 것인가
- **초보자 진입** — 기초가 없으면 대화 자체가 성립 안 함
- **교정 품질** — 근거가 2021년 리뷰뿐이라 보류
